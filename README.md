# FireWall VS PHP
Remake de PVZ pour la vidéo de CEEDZE (elle n’est pas encore sortie)

### Pour lancer le code, il faut avoir la librairie `curses`
*  Sur macOS / Linux, elle est généralement préinstallée 
*  Sur Windows, installez-la avec :  
  ```bash
  pip install windows-curses
  ```

### Puis pour lancer le script tapez : 
```
git clone https://github.com/OrAxelerator/Firewall_VS_PHP.git
```
Exécutez ```intro.py``` avec :

linux/Macos : python3 / python + intro.py

windows : py / python + intro.py

> ce jeux utilise des bruitages 🎧 !
